# أصداء+ — الحزمة الأولية

## محتويات الحزمة
- `index.html`: الواجهة العامة.
- `contribute.html`: نموذج المساهمات.
- `admin.html`: واجهة أولية للإدارة.
- `config.js`: إعدادات Supabase العامة.
- `schema.sql`: مخطط قاعدة البيانات الأولي.
- ملفات JavaScript وCSS.

## تنبيه مهم
هذه حزمة تأسيسية وليست منصة منشورة أو مكتملة الربط. يلزم إنشاء مشروع Supabase، مراجعة سياسات Row Level Security، تفعيل المصادقة والتخزين، ثم استكمال ربط الواجهات واختبارها قبل استقبال بيانات حقيقية.

لا تضع مفتاح `service_role` في ملفات الموقع. استخدم المفتاح العام anon/publishable فقط مع سياسات RLS صحيحة. لا تعتمد على لوحة الإدارة قبل تفعيل المصادقة والتحقق من صلاحيات المدير.
